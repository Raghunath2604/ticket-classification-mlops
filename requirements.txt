# torch is intentionally NOT pinned to a plain "pip install torch" here.
# Installing plain "torch" from PyPI pulls the full CUDA/GPU build —
# confirmed while building this repo: it drags in ~15 nvidia-* packages
# (cuBLAS, cuDNN, NCCL, etc.), several GB, none of which are used or
# wanted for CPU training/serving on a normal EC2 box. Install the
# CPU-only wheel first, separately:
#
#   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.13.0
#   pip install -r requirements.txt
#
# (transformers does not hard-depend on torch — it supports multiple
# backends — so this ordering is safe and won't get overridden.)
